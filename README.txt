IMAGE AND VIDEO PROCESSING USING FOURIER TRANSFORM

Files:
- image_video_fourier_transform.py: Complete Google Colab Python script.

How to run:
1. Open https://colab.research.google.com/
2. Create a new notebook.
3. Copy the contents of the .py file into a code cell, or upload the .py file
   and use %run image_video_fourier_transform.py.
4. Run the code.
5. Upload an image when prompted, then upload a video when prompted.

Requirements:
- Google Colab (provides google.colab.files)
- OpenCV (cv2)
- NumPy
- Matplotlib

The script displays the original image, grayscale image, image Fourier
magnitude spectrum, an extracted video frame, its grayscale version, and
the frame's Fourier magnitude spectrum.
